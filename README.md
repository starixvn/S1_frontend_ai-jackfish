### Rules
1. 僅使用 config 中定義的色碼/號做開發
2. 僅使用 grid 做切版，維持全站統一
3. 減少絕對定位使用 (會跳脫出 grid 容器切版流向)
4. 減少定 px 使用 ( 不利於 RWD )
> Flex是擅長一維的排版，Grid擅長二維的排版。
